# shellshocklive-aimbot
pretty much a more advanced ruler for the game ShellShock Live, with support for all resolutions, wind, and soon obstacles/walls

How to use:
1. Run `pip install -r dependencies.txt`
2. Open aimbot.py and change wt, ht to your screen resolution
3. Run aimbot.py and select your game resolution
4. Install AutoHotKey v1 and run always_ontop.ahk (couldnt figure out how to keep the window on top in the script so this tool will be necessary for now)

Controls:
WASD = **Move crosshair**
E = **Move crosshair to current mouse position**
Z = **Reset angle, power, wind, and crosshair position**
L = **Adjust angle right**
J = **Adjust angle left**
I = **Increase power**
K = **Decrease power**
Q or ESC = **Quit program**
